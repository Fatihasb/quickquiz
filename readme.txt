QuickQuiz 
Application web interactive de quiz en ligne développée avec *Django* et *MySQL*.  
Elle permet de créer, partager et participer à des quiz thématiques, avec gestion des scores, classements et gamification (badges, niveaux, récompenses).

les etapes pour demarrer projet :
python -m venv .venv
.venv\Scripts\activate
installer les dependances 
python manage.py runserver
